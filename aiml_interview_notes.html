ML Fundamentals
The core concepts every AI intern must know cold
📊
Supervised vs Unsupervised vs Reinforcement Learning
The 3 main types of ML — definition + example + when to use
▼
🏷️ Supervised Learning

Trained on labelled data — input + correct output pairs. The model learns to predict the output for new inputs.

Types: Classification (discrete output) and Regression (continuous output).

Examples: Spam detection, house price prediction, image classification.

🔍 Unsupervised Learning

No labels — the model finds hidden patterns and structure on its own.

Types: Clustering (group similar items) and Dimensionality reduction.

Examples: Customer segmentation, topic modelling, anomaly detection.

🎮 Reinforcement Learning (RL)

An agent learns by taking actions in an environment and receiving rewards or penalties. No labelled data — just trial and error.
Example: AlphaGo learning chess, robots learning to walk, recommendation systems optimising click-through rate.

Real-World Example Netflix uses supervised learning to predict your rating for a movie (from your watch history). It uses unsupervised clustering to group users with similar tastes. And it uses reinforcement learning to optimise which thumbnail to show you to maximise clicks.
💬 Interview Questions
What is the key difference between classification and regression?
Classification predicts a discrete category — yes/no, cat/dog/bird. Regression predicts a continuous numeric value — price, temperature, age. Same algorithm family (e.g., Decision Trees) can do both; the difference is the output type and loss function used.
Can you give an example of an unsupervised learning task in business?
Customer segmentation for an e-commerce company. You feed purchase history into K-Means clustering — no labels needed. The algorithm finds natural groups: "budget shoppers", "luxury buyers", "frequent returners". Marketing then tailors campaigns per segment. No one told the model what the groups should be — it discovered them.
📉
Overfitting, Underfitting & Bias-Variance Tradeoff
The most important concept in all of ML
▼

Overfitting: Model learns training data too well — memorises noise. High train accuracy, low test accuracy. Model is too complex relative to the data.

Underfitting: Model is too simple to capture the pattern. Low accuracy on both train and test. Needs more features or a more complex model.

Bias-Variance Tradeoff: Bias = how far off predictions are on average (underfitting = high bias). Variance = how much predictions vary across datasets (overfitting = high variance). The goal is a model with low bias AND low variance — they pull in opposite directions.

Example A student who memorises exam answers but can't solve new questions = overfitting. A student who never studies = underfitting. A student who understands concepts and applies them = good generalisation.
How to fix overfitting
  • More training data — the most effective fix
  • Regularization (L1/L2) — penalise large weights; forces model to stay simple
  • Dropout — randomly turn off neurons during training (neural networks)
  • Cross-validation — evaluate on multiple folds; catches overfitting early
  • Early stopping — stop training when validation loss starts increasing
  • Pruning — cut branches of decision trees that don't add value
💬 Interview Questions
Your model has 98% training accuracy but 62% test accuracy. What happened and what do you do?
Classic overfitting. The model memorised training data including noise. I'd: (1) collect more training data, (2) add regularization (L2/dropout), (3) reduce model complexity, (4) check for data leakage (train data accidentally appearing in test set), (5) use cross-validation for a better estimate of real performance.
What is L1 vs L2 regularization?
L1 (Lasso) adds the sum of absolute values of weights to the loss. It drives some weights to exactly zero — effectively doing feature selection. L2 (Ridge) adds the sum of squared weights. It shrinks all weights towards zero but rarely to exactly zero — it distributes the penalty. L1 is better when you suspect many features are irrelevant. L2 is better when all features contribute somewhat.

Linear Regression
Predict continuous values — the foundation of ML
▼

Linear Regression finds the best-fit line through data points that minimises the sum of squared errors between predicted and actual values. It models a linear relationship between input features and a continuous output.

y = w₀ + w₁x₁ + w₂x₂ + ... + wₙxₙ

Where w = weights (coefficients learned during training), x = input features, y = predicted output.

Loss function: Mean Squared Error (MSE) — average of squared differences between predicted and actual values. Training minimises this using gradient descent.

Real Example Predicting house price: price = 200 + 150×(sq_ft) + 20000×(bedrooms) - 5000×(age). Given a house with 1200 sq ft, 3 bedrooms, 5 years old → price ≈ ₹24 lakhs (hypothetical).
Python with sklearn
from sklearn.linear_model import LinearRegression from sklearn.model_selection import train_test_split import numpy as np X = np.array([[1200, 3], [1500, 4], [800, 2]]) # sqft, bedrooms y = np.array([24, 30, 16]) # price in lakhs model = LinearRegression() model.fit(X, y) prediction = model.predict([[1100, 3]]) # new house print(prediction) # → ~21.5
💬 Interview Questions
What are the assumptions of linear regression?
1. Linearity — relationship between X and y is linear. 2. Independence — observations are independent. 3. Homoscedasticity — constant variance in errors. 4. No multicollinearity — features aren't highly correlated with each other. 5. Normally distributed errors. If these are violated, the model's coefficients and predictions become unreliable.
🔀
Logistic Regression
Classification despite the "regression" name — output is a probability
▼

Despite the name, Logistic Regression is a classification algorithm. It applies a sigmoid function to a linear equation to output a probability between 0 and 1. If probability > 0.5 → class 1, else class 0.

P(y=1) = 1 / (1 + e^(−z)) where z = w₀ + w₁x₁ + ...
Example Email spam detection: given features like "contains 'free money'", "unknown sender", "all caps subject" — logistic regression outputs P(spam) = 0.92. Since > 0.5, it's classified as spam.
Key difference from Linear Regression: Linear → continuous output (price). Logistic → probability → class label (spam/not spam). Loss function is Cross-Entropy, not MSE.
💬 Interview Questions
Why can't we use linear regression for classification?
Linear regression can output any value from -∞ to +∞, which can't be interpreted as a probability. For a binary classification, we need outputs between 0 and 1. The sigmoid function squashes any value into (0,1). Also, with linear regression, outliers dramatically skew the decision boundary. Logistic regression is more robust for classification tasks.
🌳
Decision Trees & Random Forest
Intuitive, explainable models — and their ensemble upgrade
▼

Decision Tree: A tree-like flowchart of decisions. At each node, it splits the data on the feature that gives the best separation (maximum information gain / minimum Gini impurity). Leaves are the final class predictions.

Gini Impurity: Measures how mixed a node is. A node of all same class = 0 (pure). If 50/50 split = 0.5 (most impure). The algorithm always picks the split that minimises Gini impurity.

Random Forest: An ensemble of hundreds of decision trees trained on random subsets of data and features. Final prediction = majority vote (classification) or average (regression). This reduces variance and overfitting massively.

Example Loan approval: Decision tree asks → Income > ₹50k? → Credit score > 700? → Existing loans < 2? → Approve/Reject. Random forest trains 500 such trees on different data samples and takes the majority vote, making it far more reliable than a single tree.
✅ Pros of Decision Tree

Easy to visualise and explain. No feature scaling needed. Handles both categorical and numerical data. Fast prediction.

⚠️ Cons

Prone to overfitting (grows too deep). Unstable — small data change = very different tree. Not ideal for very complex relationships.

💬 Interview Questions
How does Random Forest improve over a single Decision Tree?
Random Forest uses bagging (Bootstrap AGGregating): it trains many trees on random subsets of training data (with replacement) and random subsets of features. This introduces diversity between trees. When they vote, individual errors cancel out. The result has lower variance, better generalisation, and is resistant to overfitting — at the cost of interpretability and speed.
What is the difference between Gini Impurity and Entropy?
Both measure node impurity. Gini is computationally faster (no logarithm). Entropy (from information theory) sometimes produces slightly more balanced trees. In practice, both give very similar results. Gini tends to isolate the most frequent class; entropy tends to create more balanced trees. sklearn uses Gini by default.
🔵
K-Means Clustering
The most popular unsupervised learning algorithm
▼

K-Means groups data into K clusters by minimising the distance between each point and the centroid (center) of its cluster.

Step by Step
  • Step 1: Choose K (number of clusters)
  • Step 2: Randomly initialise K centroids
  • Step 3: Assign each data point to the nearest centroid
  • Step 4: Recalculate centroids as mean of all points in the cluster
  • Step 5: Repeat steps 3-4 until centroids stop moving (convergence)
Example Segmenting 10,000 Swiggy customers into K=3 groups: Cluster 1 = "order weekly, avg ₹300" (regulars), Cluster 2 = "order once a month, avg ₹800" (special occasion), Cluster 3 = "order daily, avg ₹150" (daily lunch crowd). Swiggy can target each differently.
How to choose K? Use the Elbow Method — plot inertia (sum of squared distances from centroid) vs K. The "elbow" where the curve bends is the optimal K.
💬 Interview Questions
What is a limitation of K-Means?
1. You must specify K in advance (use Elbow method to find it). 2. Sensitive to outliers (one extreme point can pull a centroid far off). 3. Assumes spherical clusters — doesn't work well for elongated or oddly-shaped clusters (use DBSCAN instead). 4. Results vary with random initialisation (use K-Means++ for better initialisation).

Key ML Algorithms
SVM, KNN, Gradient Boosting, Naive Bayes — with when-to-use guides
🎯
K-Nearest Neighbours (KNN)
Classify by looking at your neighbours — the simplest algorithm
▼

KNN classifies a new point by finding the K nearest data points in the training set (by Euclidean distance) and taking a majority vote of their classes. No training phase — it's a "lazy learner".

Example You're recommending a movie. K=5 → find the 5 users most similar to you by watch history. 4 of them liked "Interstellar" → predict you'll like it too. This is literally how collaborative filtering (Netflix) works at its core.
✅ Pros

Simple, no training time, naturally handles multi-class, works well for small datasets, good for recommendation systems.

⚠️ Cons

Slow at prediction (computes distance to all points). Sensitive to scale — must normalise features. Struggles with high dimensions (curse of dimensionality).

Always normalise/scale features before KNN. A feature measured in thousands (salary) would dominate one measured in single digits (years) purely due to scale.
💬 Interview Questions
How do you choose K in KNN?
Use cross-validation: try K = 1, 3, 5, 7... and pick the one with the lowest validation error. Rule of thumb: K = √n (where n = training samples). Odd K is preferred to avoid ties in binary classification. Low K = overfit (too sensitive to noise), High K = underfit (too generalised, ignores local patterns).
✂️
Support Vector Machine (SVM)
Find the widest possible margin between classes
▼

SVM finds a hyperplane that best separates two classes with the maximum margin. The data points closest to the boundary are called support vectors — they define the margin. Maximising the margin improves generalisation.

For non-linearly separable data, SVM uses a kernel trick — it maps data to a higher-dimensional space where it becomes linearly separable, without actually computing in that space.

Example Classifying tumours as malignant/benign. The features (cell size, shape) might not be linearly separable in 2D. An RBF kernel maps them to 3D where a flat plane perfectly separates them. SVM finds that plane.
Common Kernels
  • Linear kernel — for linearly separable data; fast
  • RBF (Radial Basis Function) — most popular; handles non-linear; works with most data
  • Polynomial kernel — for polynomial relationships between features
💬 Interview Questions
What is the C parameter in SVM?
C is the regularization parameter. High C = small margin, fewer misclassifications on training data (may overfit). Low C = wider margin, allows more misclassifications (better generalisation). Think of C as how much you penalise misclassifications: high penalty → the model tries hard to classify everything correctly → smaller margin → overfitting risk.
🚀
Gradient Boosting & XGBoost
The algorithm that wins most Kaggle competitions
▼

Boosting: An ensemble technique that builds trees sequentially. Each new tree focuses on correcting the errors of the previous trees. Final prediction = weighted sum of all trees.

XGBoost (Extreme Gradient Boosting) is an optimised, faster implementation with built-in regularisation, missing value handling, and parallel processing. It's the industry standard for structured/tabular data.

🆚 Boosting vs Bagging

Bagging (Random Forest): Trees trained in parallel on random subsets. Reduces variance. Boosting (XGBoost): Trees trained sequentially, each fixing previous errors. Reduces bias. Boosting is usually more accurate; bagging is more robust to outliers.

📊 When to Use XGBoost

Structured/tabular data (CSV, databases). When you need high accuracy. Kaggle competitions. When features are numeric with some nulls. Not ideal for images, text (use deep learning instead).

Example Predicting loan default: Tree 1 predicts, makes some errors on high-risk customers. Tree 2 focuses on those high-risk cases. Tree 3 fixes what Tree 2 got wrong. After 100 trees, the combined model is highly accurate. Banks use XGBoost for exactly this.
💬 Interview Questions
What is the difference between Random Forest and XGBoost?
Random Forest builds trees in parallel, independently, and averages them (bagging). Reduces variance. More robust, harder to overfit. XGBoost builds trees sequentially, each correcting previous errors (boosting). Reduces bias. Generally more accurate on tabular data but more prone to overfitting if not tuned. RF is more interpretable; XGBoost typically wins on performance benchmarks.
📬
Naive Bayes
Probabilistic classifier — surprisingly effective for text
▼

Naive Bayes applies Bayes' Theorem to classify data. "Naive" because it assumes all features are independent given the class label — which is rarely true but surprisingly works well in practice.

P(class | features) ∝ P(class) × P(feature₁|class) × P(feature₂|class) × ...
Email Spam Example For a new email containing "FREE", "WIN", "CLICK": P(spam | "FREE","WIN","CLICK") ∝ P(spam) × P("FREE"|spam) × P("WIN"|spam) × P("CLICK"|spam). If this > P(not spam | words), classify as spam. It learns these probabilities from training emails.
Naive Bayes is extremely fast and works brilliantly for text classification (spam filters, sentiment analysis) despite its simplistic assumption. It's often used as a strong baseline.

Model Evaluation & Metrics
How do we know if a model is actually good?
🎯
Confusion Matrix, Precision, Recall, F1
The most important evaluation metrics — asked in almost every interview
▼

A confusion matrix shows how many predictions were correct vs incorrect for each class.

Predicted PositivePredicted Negative
Actually PositiveTP (True Positive)FN (False Negative) — missed it
Actually NegativeFP (False Positive) — false alarmTN (True Negative)
Precision

Of all the times we predicted positive, how often were we right?
TP / (TP + FP)
High precision = few false alarms. Optimise when false positives are costly (spam filter — don't mark real emails as spam).

Recall (Sensitivity)

Of all actual positives, how many did we catch?
TP / (TP + FN)
High recall = don't miss real cases. Optimise when false negatives are costly (cancer detection — don't miss a real tumour).

F1 Score = 2 × (Precision × Recall) / (Precision + Recall)

F1 Score: Harmonic mean of precision and recall. Use when both matter and dataset is imbalanced. Accuracy is misleading on imbalanced data (99% "not fraud" dataset → model that always predicts "not fraud" gets 99% accuracy but detects 0 frauds).

When to use what Cancer detection: optimise Recall (catch every case). Spam filter: optimise Precision (don't block real emails). Customer churn prediction: use F1 (care about both). Search engine ranking: use Precision@K.
💬 Interview Questions
Why is accuracy a bad metric for imbalanced datasets?
If 99% of credit card transactions are legitimate and only 1% are fraud, a model that always predicts "not fraud" gets 99% accuracy but catches zero frauds — which is useless. Instead use Precision, Recall, F1, or AUC-ROC, which measure how well the model handles the minority class (fraud). This is why in fraud detection, banking, and medical diagnosis, we never use accuracy alone.
What is AUC-ROC?
ROC (Receiver Operating Characteristic) curve plots True Positive Rate vs False Positive Rate at different classification thresholds. AUC (Area Under Curve) summarises this as a single number 0–1. AUC = 0.5 → random guessing. AUC = 1.0 → perfect model. AUC = 0.85 → model correctly ranks a random positive above a random negative 85% of the time. It's threshold-independent — useful for comparing models.
✂️
Train/Validation/Test Split & Cross-Validation
The right way to evaluate model performance without data leakage
▼

Train set (70-80%): Model learns from this. Validation set (10-15%): Used during development to tune hyperparameters and compare models. Test set (10-20%): Held out completely until final evaluation — never touch during development.

Data Leakage: When information from outside the training set "leaks" into the model during training, making it look better than it actually is. Classic mistake: normalising using statistics from the full dataset before splitting — the test set's mean/std influenced the training, so test performance is fake.

K-Fold Cross Validation Split data into K folds (e.g., 5). Train on 4 folds, test on 1. Repeat 5 times, each time using a different fold as test. Average the 5 scores. This gives a more reliable performance estimate, especially for small datasets. 5-fold CV is the standard.
Always split data FIRST, then apply any preprocessing (scaling, encoding) to train set only. Then apply the same transformation to validation/test using train set statistics.
💬 Interview Questions
What is data leakage and give an example?
Data leakage means the model has access to information it wouldn't have in production. Example: predicting if a patient will be hospitalised next month, but including "number of hospital visits this month" as a feature. That data wouldn't be available at prediction time. Another classic: including the label-derived features (e.g., using "fraud flag" to predict fraud). Leakage inflates validation scores but the model fails catastrophically in production.

Neural Networks & Deep Learning
The engine behind modern AI — architecture, training, CNNs
🧠
Neural Network Architecture & Forward Pass
Layers, neurons, weights, activation functions — how data flows
▼

A neural network is made of layers of neurons. Each neuron computes a weighted sum of its inputs + bias, then applies an activation function to introduce non-linearity. Without activation functions, stacked linear layers are still just one linear transformation.

Layer types
  • Input Layer — receives raw features (one neuron per feature)
  • Hidden Layers — learn intermediate representations; deeper = more complex patterns
  • Output Layer — final prediction (1 neuron for regression; N neurons for N-class classification)
Activation Functions
FunctionOutput RangeWhen to Use
ReLU0 to +∞Default for hidden layers — fast, avoids vanishing gradient
Sigmoid0 to 1Binary classification output layer (probability)
Softmax0 to 1 (sums to 1)Multi-class output layer (probability per class)
Tanh-1 to 1Hidden layers when negative values matter; better than sigmoid
Leaky ReLU-∞ to +∞Fixes "dying ReLU" problem; small negative slope
💬 Interview Questions
What is the vanishing gradient problem?
During backpropagation, gradients are multiplied layer by layer. Sigmoid/tanh functions have gradients between 0 and 0.25 — multiplying many small numbers together → gradient approaches 0 in early layers → those layers barely update → deep networks don't learn. Solution: use ReLU (gradient is 1 for positive inputs, no squashing), batch normalisation, or residual connections (like in ResNet which adds skip connections).
⚙️
Backpropagation & Gradient Descent
How neural networks actually learn — the core training algorithm
▼

Forward pass: Input flows through the network, producing a prediction. Loss is calculated (difference from truth).

Backward pass (Backpropagation): Using the chain rule of calculus, compute the gradient of the loss with respect to each weight. This tells us which direction to nudge each weight to reduce loss.

Gradient Descent: Update each weight: w = w - learning_rate × gradient. Learning rate controls step size — too large = overshooting, too small = very slow training.

Optimisers
  • SGD — basic; update weights after each sample; noisy but can escape local minima
  • Mini-batch SGD — update after a batch (32/64/128 samples); balance of speed and accuracy
  • Adam — Adaptive Moment Estimation; adjusts learning rate per parameter; most popular choice
  • RMSprop — good for RNNs; adapts learning rate based on recent gradient magnitudes
Analogy Imagine you're blindfolded on a hilly landscape trying to reach the valley (minimum loss). Each step, you feel the slope (gradient) and take a step downhill (gradient descent). The step size is the learning rate. Too big a step and you jump over the valley. Too small and it takes forever. Adam is like having a smart guide who adjusts your step size dynamically.
💬 Interview Questions
What is the difference between batch gradient descent and mini-batch?
Batch GD: uses all training data to compute one gradient update. Very stable but extremely slow for large datasets. Mini-batch GD: uses a random subset (e.g., 64 samples). Much faster, has some noise that helps escape local minima, is the standard in practice. Stochastic GD: one sample at a time — fastest updates but very noisy. Mini-batch is the sweet spot used in virtually every neural network training pipeline today.
🖼️
Convolutional Neural Networks (CNN)
The architecture for images, video, and anything spatial
▼

CNNs use convolutional layers that apply learnable filters (kernels) to detect local features — edges, textures, shapes in images. Key advantage: parameter sharing — the same filter is used across the entire image, massively reducing parameters vs a fully connected network.

CNN Layer Types
  • Conv Layer — applies filters to detect features (edges, textures); outputs feature maps
  • ReLU — activation after each conv layer
  • Pooling (Max/Avg) — reduces spatial dimensions; adds translation invariance (cat is a cat anywhere in image)
  • Flatten — convert 2D feature maps to 1D vector
  • Fully Connected (Dense) — final classification layers
Real Application Google Photos face recognition: first conv layers detect edges → deeper layers detect eyes, noses → final layers detect faces. Same architecture used in medical imaging (tumour detection in X-rays), self-driving car lane detection, and document scanner apps.
💬 Interview Questions
Why do we use Pooling layers in CNNs?
Pooling (typically Max Pooling) reduces the spatial size of feature maps, which: (1) reduces computation and parameters, (2) adds translation invariance — the model recognises a cat whether it's in the top-left or bottom-right of the image, (3) helps prevent overfitting by discarding precise positional information and keeping only the dominant features. A 4×4 feature map → 2×2 after max pooling (75% fewer values to process in next layer).

NLP & Transformers
The core of modern AI — this section is critical for AI intern roles
🔤
Text Processing: Tokenization, Embeddings, TF-IDF
How computers understand text — from characters to meaning
▼

Tokenization: Splitting text into units (tokens). Can be words, subwords, or characters. Modern LLMs use subword tokenization (BPE / WordPiece) — "unhappiness" → ["un", "happiness"]. This handles rare words gracefully.

Word Embeddings: Map words to dense numerical vectors where similar words have similar vectors. The vector captures semantic meaning.

Word2Vec magic king - man + woman ≈ queen. "Paris" - "France" + "Germany" ≈ "Berlin". These relationships emerge automatically from training on large text corpus. This is what makes embeddings so powerful.
Embedding types
  • Word2Vec — static embeddings; each word has one fixed vector regardless of context
  • GloVe — similar to Word2Vec; trained on global co-occurrence statistics
  • Contextual (BERT) — same word gets different vector based on context. "bank" in "river bank" ≠ "bank account"

TF-IDF (Term Frequency-Inverse Document Frequency): Measures how important a word is to a document in a corpus. High TF-IDF = word appears often in this doc but rarely in others (= distinctive). Used in search engines and keyword extraction.

TF-IDF = TF(t,d) × log(N / df(t))
💬 Interview Questions
What is the difference between Word2Vec and BERT embeddings?
Word2Vec is a static embedding — "Apple" always maps to the same vector whether in "Apple iPhone" or "apple pie". BERT produces contextual embeddings — the same word gets a different vector based on surrounding words. This is why BERT understands "I went to the river bank" vs "I went to the bank to deposit money" correctly. BERT representations are far richer and power modern NLP applications.
⚡
Transformers & Self-Attention (MUST KNOW)
The architecture powering GPT, BERT, and every modern LLM
▼

The Transformer (introduced in "Attention Is All You Need", 2017) processes sequences in parallel using self-attention, unlike RNNs which process sequentially. This makes training dramatically faster and allows capturing long-range dependencies.

Self-Attention — the key idea

For each word in a sequence, self-attention computes how much attention to pay to every other word. It creates three vectors per word: Query (Q), Key (K), Value (V).

Attention(Q, K, V) = softmax(QKᵀ / √d_k) × V
Intuition Sentence: "The animal didn't cross the street because it was too tired." — What does "it" refer to? Self-attention lets the word "it" strongly attend to "animal". The model learns these relationships automatically from training data.
Transformer Architecture
  • Encoder — reads and understands input; produces rich contextual representations
  • Decoder — generates output sequence token by token
  • Multi-head Attention — runs attention multiple times in parallel (different "perspectives")
  • Positional Encoding — since there's no recurrence, position info is added to embeddings
  • Feed-forward layers — applied after attention in each block
  • Layer normalisation — stabilises training
ModelArchitectureBest For
BERTEncoder-onlyUnderstanding text — classification, NER, QA
GPTDecoder-onlyGenerating text — chatbots, completion, summarisation
T5 / BARTEncoder-DecoderSeq-to-seq — translation, summarisation
💬 Interview Questions
Explain transformers to a non-technical person.
Imagine reading a book with a sticky note for every word, and each sticky note tells you which other words are related and how much. Transformers do this for every word simultaneously — each word "pays attention" to relevant context words, no matter how far apart. This lets the model understand "it was tired" refers to "the animal" even at the start of the sentence. And unlike reading one word at a time, it reads the whole sentence in parallel — making it very fast.
Why did transformers replace RNNs/LSTMs?
RNNs process tokens one by one — can't parallelise, slow to train. They also struggle with long-range dependencies (information from early tokens gets "forgotten" by the time we process late tokens, despite LSTMs helping). Transformers: (1) process all tokens in parallel → 10-100x faster training, (2) self-attention lets any token directly attend to any other token regardless of distance, (3) scale much better with more data and compute.
What is positional encoding in transformers?
Since transformers process all tokens simultaneously (not sequentially), they have no inherent sense of word order. "Dog bites man" and "Man bites dog" would look the same without position info. Positional encoding adds a unique vector to each token embedding based on its position, so the model knows which word came first, second, etc. The original paper used sine/cosine functions of different frequencies; modern models often learn positional embeddings during training.

🤖
Large Language Models (LLMs) — How They're Built
Pre-training → Fine-tuning → RLHF — the 3-stage training pipeline
▼
Stage 1: Pre-training

Train a giant transformer on massive text data (Common Crawl, Wikipedia, books). Task: predict the next token given context. This teaches the model language, world knowledge, reasoning, and code. GPT-4 was trained on ~10 trillion tokens. Cost: tens of millions of dollars in compute.

Stage 2: Fine-tuning (SFT)

Take the pre-trained model and train further on a smaller, high-quality dataset of instruction-response pairs. This teaches it to be helpful and follow instructions. Example: fine-tune on 10,000 examples of "instruction → ideal response".

Stage 3: RLHF (Reinforcement Learning from Human Feedback)

Human raters compare model outputs and rank them. A Reward Model is trained to predict human preference. Then the LLM is fine-tuned to maximise this reward using RL (PPO algorithm). This is what makes ChatGPT helpful, harmless, and honest.

Analogy Pre-training = reading every book ever written (general knowledge). Fine-tuning = taking a course on customer service (specific task). RLHF = getting feedback from customers and improving your responses based on what they liked (alignment with preferences).
💬 Interview Questions
What is RLHF and why is it important?
RLHF (Reinforcement Learning from Human Feedback) aligns LLMs with human values and preferences. Without it, a model trained to predict text might generate harmful content, be sycophantic, or give confidently wrong answers. RLHF teaches the model what "good" looks like by learning from human rankings of model outputs, then optimising the model to produce those preferred outputs. It's what turns a raw language model into ChatGPT.
🔍
RAG — Retrieval-Augmented Generation
How to give LLMs knowledge beyond their training data
▼

RAG combines a retrieval system (search over your documents) with a generative LLM. Instead of relying purely on training data, the LLM can look up relevant information at inference time and include it in its context.

RAG Pipeline
  • Ingestion: Take your documents → split into chunks → convert to embeddings → store in vector database (Pinecone, pgvector, Weaviate)
  • Retrieval: User query → convert to embedding → find top-K most similar chunks via cosine similarity
  • Augmentation: Inject retrieved chunks into the LLM prompt as context
  • Generation: LLM answers using both its training knowledge + retrieved context
Real Example — Your PromptRoute experience applies here! CirrusLabs enterprise chatbot: upload 1000 internal policy PDFs → chunk + embed → store in vector DB. User asks "What's the leave policy for remote employees?" → retrieve top 3 relevant chunks → LLM answers accurately with citations. Without RAG, the LLM would either make up an answer or say "I don't know".
You built a RAG chatbot for ruthvikrr.in! Mention this: "I built a production RAG system using Node.js, pgvector, Groq, and Xenova embeddings. I debugged vector dimension mismatches and implemented rate limiting."
💬 Interview Questions
What is the difference between fine-tuning and RAG? When would you choose each?
Fine-tuning bakes knowledge into model weights — good for teaching consistent style/behavior, domain-specific language, or reasoning patterns. Expensive to update when knowledge changes. RAG retrieves knowledge at runtime — good for factual, frequently-updated information (policies, product docs, legal texts). Easy to update — just update the document store. Choose RAG for knowledge-intensive tasks with changing data. Choose fine-tuning for consistent formatting, tone, or domain-specific generation styles. Often combine both for best results.
What is "hallucination" in LLMs?
Hallucination is when an LLM generates plausible-sounding but factually incorrect information with high confidence. Example: GPT might invent a fake research paper with a real-sounding author and journal title. It happens because LLMs are trained to predict likely next tokens — not to verify truth. Mitigations: RAG (ground answers in real documents), temperature=0 (more deterministic), asking the model to cite sources, and having the model say "I don't know" when uncertain.
💡
Prompt Engineering
Getting the best out of LLMs — CoT, few-shot, system prompts
▼

Prompt engineering is the practice of crafting inputs to LLMs to get reliable, high-quality outputs. It's a key skill for AI interns at companies building AI products.

Key Techniques
  • Zero-shot prompting — just ask the question; no examples. Works for simple tasks.
  • Few-shot prompting — provide 2-5 examples of input→output before your actual question. Model learns the pattern from examples.
  • Chain-of-Thought (CoT) — ask model to "think step by step". Dramatically improves reasoning on math/logic problems.
  • System prompt — set context and persona before the conversation. "You are a helpful customer support agent for CirrusLabs…"
  • ReAct (Reason + Act) — model alternates between reasoning and taking actions (calling tools, searching). Used in AI agents.
  • Self-consistency — generate multiple responses and take majority answer. More reliable for tricky questions.
CoT Example Without CoT: "What is 23 × 47?" → "1081" (often wrong).
With CoT: "Think step by step: 23 × 47 = 23 × 40 + 23 × 7 = 920 + 161 = 1081." → Correct. CoT forces the model to show its work, catching errors at each step. This is why you built PromptRoute — classifying which technique to apply!
💬 Interview Questions
Why does Chain-of-Thought prompting improve LLM performance?
CoT forces the model to decompose complex problems into intermediate steps. Instead of trying to predict the final answer in one leap (which requires holding too much in context), it works through sub-problems sequentially. Each step is simpler to get right. It also makes errors visible and correctable. Research shows CoT can improve performance on multi-step math and logic problems by 30-50% compared to direct prompting.
🎨
GANs & Diffusion Models
Generative models for images — Stable Diffusion, DALL-E, Midjourney
▼

GAN (Generative Adversarial Network): Two networks compete — the Generator tries to create fake images realistic enough to fool the Discriminator. The Discriminator tries to distinguish real from fake. They train together until Generator produces convincing images. Used for: deepfakes, face generation (ThisPersonDoesNotExist.com), image-to-image translation.

Diffusion Models: Train by gradually adding noise to an image until it's pure noise, then learn to reverse this process (denoise step by step). Generation = start from random noise, denoise 50-1000 steps guided by a text prompt. More stable to train than GANs, better quality.

Examples GANs: StyleGAN (hyperrealistic face generation), CycleGAN (horse→zebra, summer→winter). Diffusion: Stable Diffusion, DALL-E 3, Midjourney, Adobe Firefly. Most modern image generation is now diffusion-based.
💬 Interview Questions
What is "mode collapse" in GANs?
Mode collapse happens when the Generator finds one type of output that fools the Discriminator and keeps generating only that — producing very similar outputs with no diversity. For example, a GAN trained on faces might only generate blond women. Solutions include training multiple Generators, using Wasserstein loss (WGAN), or mini-batch discrimination. This is a major practical challenge with GANs and one reason diffusion models have become preferred.

Feature Engineering & Data Preprocessing
Garbage in, garbage out — data quality determines model quality
🔧
Scaling, Encoding, Missing Values
The unglamorous work that makes or breaks a model
▼
Feature Scaling
  • Min-Max Normalisation — scales to [0,1]. Good when you need bounded output. Sensitive to outliers. (x - min) / (max - min)
  • Standardisation (Z-score) — mean=0, std=1. Better for algorithms assuming normal distribution (SVM, PCA, linear regression). (x - mean) / std
  • When NOT needed: Decision Trees and Random Forest — they split on thresholds, scale doesn't matter.
  • When essential: KNN, SVM, neural networks, PCA — they use distances or gradient descent.
Encoding Categorical Features
  • One-Hot Encoding — create binary column per category. "City: Mumbai/Delhi/Chennai" → 3 binary columns. Use for nominal (no order) categories with few values.
  • Label Encoding — assign integer per category (Mumbai=0, Delhi=1). Use only for ordinal data (small/medium/large) or tree-based models.
  • Target Encoding — replace category with mean of target variable. Powerful but risk of leakage if not done carefully.
Handling Missing Values
  • Drop rows/columns — if missing < 5% of rows, or column has > 80% missing. Quick but loses data.
  • Mean/Median imputation — replace with mean (numerical, no outliers) or median (outliers present). Simple and often fine.
  • Mode imputation — for categorical: fill with most frequent value.
  • KNN imputation — fill missing values based on similar rows. More sophisticated.
  • Model-based imputation — train a model to predict missing feature from other features.
Common Mistake Filling missing values with the mean calculated on the ENTIRE dataset (including test set) = data leakage. Always compute statistics on the TRAINING set only, then apply to test set.
💬 Interview Questions
Why do we use median instead of mean for imputation sometimes?
The mean is sensitive to outliers. If house prices are: [20L, 25L, 22L, 150L], the mean is 54.25L but most houses are around 22L. The median (23.5L) is more representative. Use median when the data has outliers — which is common in real-world data like income, prices, or durations. Median is a "robust statistic" — it doesn't change much when you add an extreme value.
📐
Dimensionality Reduction — PCA & t-SNE
When you have too many features — reduce without losing information
▼

PCA (Principal Component Analysis): Finds the directions (principal components) in which data varies most, and projects data onto a lower-dimensional space while retaining maximum variance. The components are orthogonal (uncorrelated).

PCA Example 100 features describing a customer (age, spending habits, click patterns…). PCA finds the top 10 "directions of variation" that capture 95% of the data's information. Now you train on 10 features instead of 100 — 10x faster, less overfitting, often better performance.

t-SNE: A non-linear dimensionality reduction technique mainly used for visualisation. Maps high-dimensional data to 2D/3D while preserving local neighbourhood structure. Great for exploring whether clusters exist in your data. NOT suitable for actual model training (not deterministic, doesn't preserve global structure).

💬 Interview Questions
When would you use PCA vs t-SNE?
PCA: when you need to reduce features for model training, remove multicollinearity, speed up computation, or reduce noise. It's linear, fast, interpretable, and reproducible. t-SNE: purely for visualisation of high-dimensional data — to explore if clusters exist. It's non-linear, slow, non-deterministic (varies per run), and the dimensions have no interpretable meaning. Never use t-SNE as a preprocessing step for training.

💬 Interview Questions
What is model drift and how do you detect/handle it?
Data drift: the statistical distribution of input features changes over time (e.g., customer demographics shift). Concept drift: the relationship between features and target changes (e.g., fraudsters change their patterns). Detection: monitor input feature distributions (PSI, KL divergence), and track model performance metrics over time. Response: alert on drift, retrain on recent data, potentially update features. For example, a COVID lockdown dramatically drifted all consumer behaviour models — companies had to retrain monthly instead of annually.
What is A/B testing in ML?
A/B testing in ML means deploying two model versions simultaneously to different user groups and measuring real-world performance. Group A gets the old model, Group B gets the new model. After enough traffic (statistical significance), compare metrics. This validates offline improvements (lower loss) actually translate to real-world gains (higher click rate, lower churn). Online metrics can differ from offline — a model better by 2% F1 offline might improve revenue by 0% online due to unrelated factors.

AI Ethics & Responsible AI
Enterprise AI companies care deeply about this — CirrusLabs especially
⚖️
Bias, Fairness & Explainability
Real-world AI must be fair, transparent, and accountable
▼
Types of AI Bias
  • Historical bias — training data reflects past inequalities (e.g., historical hiring data that skewed male for tech roles)
  • Representation bias — some groups underrepresented in training data (facial recognition failing on dark skin tones)
  • Measurement bias — proxy features introducing bias (using ZIP code as proxy for race in loan approval)
  • Feedback loop bias — biased predictions → biased outcomes → biased new data → more biased model
Explainability Tools
  • SHAP (SHapley Additive exPlanations) — shows each feature's contribution to a specific prediction. "Loan denied because: income (-0.3), credit score (+0.1), location (-0.2)…"
  • LIME — creates a local linear approximation around any prediction to explain it
  • Attention weights — in transformers, show which input tokens the model attended to
  • Feature importance — in tree-based models, which features were used most in splitting
Real Case — Amazon's Recruiting AI Amazon built an AI to screen resumes. It learned to penalise resumes containing "women's" (as in "women's chess club") because it was trained on historical hiring data dominated by male engineers. They scrapped the system. Lesson: bias in training data → biased model → real harm. Always audit for bias before deployment.
💬 Interview Questions
What is the trade-off between model accuracy and explainability?
Generally, more complex models (deep learning, XGBoost) are more accurate but harder to explain. Simpler models (logistic regression, decision trees) are more explainable but often less accurate. In high-stakes domains (loan approval, medical diagnosis, hiring), explainability is mandatory — regulations like GDPR require "right to explanation". In lower-stakes domains (recommendation systems), accuracy may trump explainability. Tools like SHAP help bridge this gap — you can use a complex model and still explain individual predictions.
What are the key principles of Responsible AI?
Fairness — model doesn't discriminate based on protected attributes (race, gender, age). Transparency — how the model makes decisions is understandable. Accountability — humans are responsible for AI decisions, not "the algorithm". Privacy — training data collected with consent, anonymised where possible. Safety — model doesn't cause physical, psychological, or social harm. Reliability — model behaves consistently and predictably. These are part of Microsoft and Google's responsible AI frameworks — and what CirrusLabs would implement for enterprise clients.
