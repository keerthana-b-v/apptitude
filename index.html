Likely Oral Questions — AI/ML
What is the difference between supervised and unsupervised learning?
Answer: In supervised learning, the model is trained on labelled data — input-output pairs — like predicting house prices using past sales. In unsupervised learning, there are no labels; the model finds hidden patterns, like grouping customers by behaviour using K-Means clustering.
How does a decision tree decide where to split?
Answer: It splits on the feature that gives the maximum information gain, measured by reducing entropy or Gini impurity. At each node, it picks the threshold that best separates the classes. The tree grows until all nodes are pure or a stopping criterion (max depth, min samples) is met.
What is overfitting and how do you fix it?
Answer: Overfitting is when a model learns the training data too well including noise, so it performs poorly on new data. I fix it using: regularization (L1/L2), dropout in neural networks, more training data, cross-validation, or pruning (decision trees). The key is to reduce model complexity relative to the data.
Explain how a transformer works (since you're applying for AI intern)
Answer: A transformer processes sequences in parallel using a self-attention mechanism, which lets each word in a sentence "look at" all other words to understand context. It has an encoder (understand input) and a decoder (generate output). Models like BERT use only the encoder for tasks like classification; GPT uses the decoder for text generation.

🎯 Redundancy Scenario — They WILL do this
They'll show you a table like:

EmployeeID | Name | Dept | DeptHead | DeptLocation

Your answer: This violates 3NF. DeptHead and DeptLocation are not dependent on the primary key (EmployeeID) — they depend on Dept. This is a transitive dependency causing redundancy. Fix by splitting into two tables: Employees(ID, Name, DeptID) and Departments(DeptID, DeptHead, DeptLocation).
Likely Oral SQL Questions
What is the difference between WHERE and HAVING?
WHERE filters rows before grouping. HAVING filters after GROUP BY — it works on aggregated results. Example: WHERE salary > 50000 vs HAVING COUNT(*) > 5.
What is normalization? Why do we need it?
Normalization is organizing a database to reduce data redundancy and improve data integrity. 1NF: atomic values, no repeating groups. 2NF: no partial dependencies. 3NF: no transitive dependencies. It prevents update anomalies — if a department manager changes, you update only one row, not hundreds.

Likely Oral Questions — Testing
What is the difference between Regression Testing and Retesting?
Retesting means re-running a specific test that previously failed, after the bug is fixed. Regression Testing means running the full test suite to ensure the fix didn't break other features. Retesting is targeted; regression is broad.
What is the difference between SDLC and STLC?
SDLC (Software Development) covers the entire product lifecycle: requirement → design → development → testing → deployment → maintenance. STLC (Software Testing) is a subset: requirement analysis → test planning → test case design → test execution → defect reporting → test closure. Testing runs within the development lifecycle.

Likely Oral Questions — Agile
What happens in a Sprint Retrospective? Why is it important?
The team reviews what went well, what didn't, and what to improve in the next sprint. The Scrum Master facilitates. It's important because it enables continuous improvement — not just in the product, but in the team's process and collaboration. Without retros, teams repeat the same mistakes.
What is the Product Owner's role? How is it different from a Project Manager?
The Product Owner defines and prioritizes the product backlog, represents the business/customer, and decides what gets built and in what order. A Project Manager focuses on timelines, resources, and delivery. In Scrum, the PO owns the "what" and "why"; the team owns the "how."
How does Agile handle a sudden change in requirements from the client?
In Agile, requirements can change between sprints. The Product Owner updates the backlog, re-prioritizes, and the team picks up the new requirement in the next sprint. We don't disrupt the current sprint — only in urgent cases. This is the key advantage over Waterfall where late changes are expensive.

Likely Oral Questions — Cloud/CI/CD
What is the difference between CI and CD?
CI (Continuous Integration) = developers frequently merge code into a shared repo; automated tests run on every merge to catch bugs early. CD (Continuous Delivery) = after CI passes, code is automatically deployed to a staging environment and is always ready to go to production. Continuous Deployment goes one step further — auto-deploys directly to production without manual approval.
What is the difference between a container (Docker) and a Virtual Machine?
A VM virtualizes the entire OS — heavy, slow to start (minutes), has its own kernel. A container shares the host OS kernel — lightweight, starts in seconds, uses less RAM. Docker packages your app + dependencies into a container that runs consistently anywhere: dev laptop, staging, or cloud.

🤖 AI / ML — (They'll focus HERE for AI intern)
01What is the difference between supervised and unsupervised learning?▼
Supervised learning uses labelled data — the model learns from input-output pairs. Examples: spam detection (email → spam/not spam), house price prediction. Unsupervised learning has no labels — the model finds patterns on its own. Examples: customer segmentation with K-Means, topic modelling with LDA. I'd use supervised for tasks where I have historical outcomes, and unsupervised for exploration when I don't.
02What is overfitting? How do you prevent it?▼
Overfitting happens when a model memorizes training data including noise, so it fails on new data — high train accuracy, low test accuracy. I prevent it by: regularization (L1/L2 penalizes large weights), dropout (randomly disabling neurons during training), cross-validation, early stopping, and collecting more training data. The goal is a model that generalizes, not memorizes.
03Explain how a neural network learns.▼
A neural network learns through forward propagation + backpropagation. In the forward pass, input flows through layers, each applying weights + activation functions, producing a prediction. We calculate the loss (difference from actual output). In backpropagation, we compute the gradient of the loss with respect to each weight using the chain rule. Gradient descent then updates weights to reduce the loss. This repeats for many epochs until the model converges.
04What is a transformer? Why is it used in modern AI?▼
A transformer is a neural network architecture that uses self-attention to process all tokens in a sequence simultaneously (unlike RNNs which process one at a time). Self-attention lets each word "look at" every other word to understand context — so "bank" in "river bank" and "bank account" gets different representations. Transformers power BERT, GPT, and most modern NLP models. They're faster to train (parallelizable) and capture long-range dependencies better than older architectures.
05What is precision vs recall? When would you optimize for each?▼
Precision = of all predicted positives, how many were actually positive? (minimize false positives). Recall = of all actual positives, how many did we catch? (minimize false negatives). Use-case: for cancer detection, optimize recall — missing a real case (false negative) is worse than a false alarm. For spam filtering, optimize precision — you don't want to mark real emails as spam. F1-score balances both when you need both.
📊 Data Structures & Algorithms
06Difference between Stack and Queue with real examples?▼
Stack (LIFO) — Last In First Out. Operations: push, pop. Real examples: browser back button (last page visited is first to return to), undo/redo in editors, function call stack in programming. Queue (FIFO) — First In First Out. Operations: enqueue, dequeue. Real examples: print queue (first submitted = first printed), CPU scheduling, WhatsApp message delivery.
07Write code to check if a string is a palindrome. Explain Big O.▼
def is_palindrome(s): s = s.lower().replace(" ", "") return s == s[::-1] Time complexity: O(n) — we compare the string with its reverse, each taking O(n) time. Space complexity: O(n) — the reversed string creates a new copy. Edge cases: empty string → True (by convention), single char → True, spaces and case handled by normalization.
08What is the difference between a singly and doubly linked list?▼
A singly linked list has nodes where each node points only to the next node. You can only traverse forward. Memory-efficient. A doubly linked list has nodes with pointers to both the next and previous nodes. You can traverse in both directions, which makes operations like delete-from-end O(1) instead of O(n). Trade-off: doubly linked lists use more memory per node.

10Given a table — identify the normalization violations (redundancy).▼
Framework to answer:
1NF violation: multiple values in one cell (e.g., "skills: Python, Java, SQL" in one column) → split to separate rows.
2NF violation: a non-key column depends on only part of a composite key → split the table.
3NF violation (most common): a non-key column depends on another non-key column (transitive dependency). Example: EmployeeID → DeptID → DeptManager — DeptManager doesn't directly depend on EmployeeID. Fix: separate Departments table.
11What is the difference between INNER JOIN and LEFT JOIN?▼
INNER JOIN returns only rows where there's a match in BOTH tables. If a row in table A has no corresponding row in table B, it's excluded. LEFT JOIN returns ALL rows from the left table, plus matched rows from the right. Where there's no match, the right side shows NULL. Use LEFT JOIN when you want all records from one table regardless of whether a match exists — e.g., all employees even if they don't have a department assigned yet.

🔄 Agile & Scrum
14Explain the Scrum framework in 2 minutes.▼
Scrum divides work into sprints — typically 2-week time-boxed cycles. The team has 3 roles: Product Owner (prioritizes the backlog), Scrum Master (facilitates and removes blockers), and the Development Team (builds). Each sprint starts with Sprint Planning where the team picks items from the product backlog. Daily standups keep everyone aligned (what I did, what I'll do, any blockers). Sprint ends with a Review (demo to stakeholders) and Retrospective (how to improve). This ensures working software is delivered every 2 weeks.
15What is the difference between Agile and Waterfall?▼
Waterfall is linear and sequential — gather all requirements → design everything → build everything → test everything → deploy. Changes mid-project are expensive and slow. Agile is iterative — work in short sprints, deliver working software every 2 weeks, adapt to changing requirements continuously. Waterfall works for fixed-scope projects (e.g., government contracts). Agile is better for products where requirements evolve — which is most software today.
☁️ Cloud & CI/CD
16What is the difference between IaaS, PaaS, and SaaS?▼
IaaS (Infrastructure as a Service) — rent raw compute, storage, networking. You manage OS and above. Example: AWS EC2, Azure VM. PaaS (Platform as a Service) — cloud manages OS + runtime; you manage just your code. Example: AWS Elastic Beanstalk, Google App Engine, Azure App Service — deploy code, not servers. SaaS (Software as a Service) — cloud manages everything; you just use the app. Example: Gmail, Salesforce, Notion. As an AI intern, I'd use PaaS like SageMaker for model training without worrying about infrastructure.

🐍 OOP & Coding
18Explain encapsulation with a code example. (MOST ASKED at CirrusLabs)▼
Encapsulation means bundling data and the methods that operate on that data within a class, and restricting direct access to internal state via access modifiers. class BankAccount: def __init__(self, balance): self.__balance = balance # private — can't be accessed directly def deposit(self, amount): if amount > 0: self.__balance += amount def get_balance(self): return self.__balance acc = BankAccount(1000) acc.deposit(500) print(acc.get_balance()) # 1500 Why it matters: External code can't set acc.__balance = -9999999 directly. All changes go through controlled methods, ensuring data integrity.
19Write a function to check if a year is a leap year.▼
def is_leap_year(year): # Divisible by 4 AND (not divisible by 100 OR divisible by 400) return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0) # Test cases: # 2024 → True (div by 4, not 100) # 2000 → True (div by 400) # 1900 → False (div by 100 but NOT 400) # 2023 → False (not div by 4) The gotcha: 1900 is NOT a leap year even though it's divisible by 4 (because it's divisible by 100 but NOT 400). Always mention this edge case!
