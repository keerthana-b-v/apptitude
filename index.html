The golden rule for Work & Time
Always convert to "work done per day" first. If A takes 6 days → A does 1/6 per day. If B takes 12 days → B does 1/12 per day. Together = 1/6 + 1/12 = 3/12 = 1/4 per day → takes 4 days. This one move solves 90% of problems.

📋 The Ultimate Time & Work Cheat Sheet

1. Fraction of Work (Q2)
Find how much work is done in a few days.
Fraction Done = Days Worked ÷ Total Days Needed
2. Group / Inverse Men (Q3, 7, 23)
When workers change, time changes inversely.
New Days = (Old Men × Old Days) ÷ New Men
3. Both Together Pattern (Q1, 4)
Have individual times, need them working together.
Together Time = (A × B) ÷ (A + B)
4. One Person Alone (Q5)
Have 'together' time & one person's time.
Other Person = (Alone × Together) ÷ (Alone − Together)
5. Efficiency / Faster Pattern (Q6)
When one person is X times faster.
Work Blocks = Together Days × (Sum of Ratios)
Alone Time = Total Blocks ÷ Person's Speed
6. Timeline / Mid-Way Left (Q9)
When someone leaves after a few days.
1. Total Pieces = LCM of days
2. Speeds = Total Pieces ÷ Individual Days
3. Rem. Work = Total Pieces − (Days Worked × Starting Speed)
4. Rem. Days = Rem. Work ÷ New Combined Speed

⏰ CLOCK CHEAT SHEET

1. The Big Gap Rule
Gap between any two numbers on the clock.
360° ÷ 12 = 30°
2. Minute Hand Speed
The long hand travels 360° in 60 mins.
360 ÷ 60 = 6° every minute
3. Hour Hand Speed
The short hand moves 30° in 60 mins.
30 ÷ 60 = 0.5° every minute
4. The 2-Second Angle Formula
Exact angle between hands. Ignore negative sign.
Angle = | (30 × H) − (5.5 × M) |

🧩 NUMBER SERIES RULES

1. Constant Gap
Adding or subtracting the same number.

2. Multiplier
Multiplying by the same number every time.

The gap itself changes step-by-step.
Example: +1, +2, +3

🐍 PYTHON CODING CHEAT SHEET (QUICK TRICKS)

1. Reverse a String
Read from end to start.
s = "hello" print(s[::-1]) # olleh
2. Reverse a Number
Take last digit repeatedly.
n = 1234 rev = 0 while n > 0: digit = n % 10 rev = rev * 10 + digit n = n // 10 print(rev) # 4321
3. Palindrome
Same forward and backward.
s = "madam" if s == s[::-1]: print("Palindrome")
4. Fibonacci Series
Next = previous two numbers sum.
a = 0 b = 1 for i in range(6): print(a) a, b = b, a + b
5. Factorial
Multiply numbers from 1 to n.
n = 5 fact = 1 for i in range(1, n + 1): fact = fact * i print(fact) # 120
6. Armstrong Number
Sum of cubes of digits = original.
n = 153 temp = n total = 0 while n > 0: digit = n % 10 total += digit**3 n = n // 10 if temp == total: print("Armstrong")
7. Prime Number
Only divisible by 1 and itself.
n = 7 count = 0 for i in range(1, n + 1): if n % i == 0: count += 1 if count == 2: print("Prime")
8. Swap Two Numbers
Easy Python trick.
a = 5 b = 10 a, b = b, a
9. Count Vowels
Check against string of vowels.
s = "hello" count = 0 for ch in s: if ch in "aeiou": count += 1 print(count)

🤖 CORE MACHINE LEARNING BASICS

Supervised vs Unsupervised
Supervised: Learns using labeled data (input + answer key). Ex: House prices.

Unsupervised: Learns from unlabeled data. Must find hidden patterns. Ex: Grouping shoppers.
Overfitting & Prevention
Overfitting: Memorizes training data too much, fails on new data.

Prevention: Use more data, use Regularization, or simplify the model.
Bias-Variance Tradeoff
Bias: Making overly simple assumptions (Underfitting).

Variance: Extreme sensitivity to small data fluctuations (Overfitting). Goal is a middle ground.

📊 EVALUATION METRICS

Is Accuracy always good?
No! Accuracy is highly misleading for imbalanced datasets.

Example: A rare disease detector that always guesses "Healthy" will be 99% accurate but useless.
Precision vs Recall
Precision: Out of all predicted positives, how many were actual positives?

Recall: Out of all actual positives, how many did the model catch?

🧠 DEEP LEARNING & DATA PREP

Activation Functions
Without them, neural nets only solve straight-line problems. Functions like ReLU or Sigmoid introduce non-linearity for learning complex shapes.
CNN vs RNN
CNN: Best for spatial data like images and video.

RNN: Best for sequential data like text, time-series, or audio.
Missing Values & One-Hot
Missing data: Drop, Impute (Mean/Median/Mode), or Flag.

One-Hot Encoding: Turns text categories into binary (1s and 0s) columns.
